## How to Run

### Using Browser

1. Open the required lab folder.
2. Open the HTML file in a browser.
3. Open **Developer Tools → Console** to see the output.

### Using Node.js

Open the terminal inside the lab folder and run:

```bash
node script.js
```

Replace `script.js` with the name of the JavaScript file you want to execute.
